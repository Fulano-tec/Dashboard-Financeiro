# 💰 Finance Dashboard

Um dashboard financeiro moderno desenvolvido com HTML, CSS e JavaScript puro para controle de receitas, despesas e análise financeira visual.

---

# 🚀 Funcionalidades

* Cadastro de receitas e despesas
* Edição de transações
* Remoção de transações
* Filtros por tipo e mês
* Resumo financeiro automático
* Exportação de dados em CSV
* Persistência de dados com LocalStorage
* Dashboard responsivo
* Gráficos financeiros dinâmicos

---

# 📊 Gráficos Disponíveis

### Doughnut Chart

Comparação entre receitas e despesas.

### Pie Chart

Distribuição de gastos por categoria.

### Line Chart

Evolução do saldo acumulado.

### Stacked Bar Chart

Receitas e despesas distribuídas por mês.

---

# 🛠 Tecnologias Utilizadas

* Chart.js

# ▶️ Como Executar o Projeto

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/finance-dashboard.git
```

2. Abra a pasta do projeto

3. Execute o arquivo:

```bash
index.html
```

O sistema iniciará diretamente no navegador.

---

# 💾 Armazenamento Local

As transações são armazenadas utilizando:

```javascript
localStorage
```

Os dados permanecem salvos mesmo após fechar o navegador.
